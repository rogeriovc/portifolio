# Currículo - Rogério Vicente

Currículo profissional desenvolvido em HTML e CSS, com foco em:
- versão web responsiva
- geração de PDF
- impressão em uma página A4

##  Objetivo
Apresentar meu perfil como Desenvolvedor Web Júnior, destacando:
- tecnologias
- experiência prática
- projetos desenvolvidos

##  Tecnologias utilizadas
- HTML5
- CSS3 (Flexbox, Media Queries, Print Styles)
- Google Fonts
- Material Design Icons

##  Versões
- Versão web (visualização online)
- Versão PDF (gerada via navegador)
- Versão otimizada para impressão

##  Diferenciais
- Layout limpo e profissional
- CSS específico para impressão (@media print)
- Links clicáveis no PDF
- Conteúdo objetivo e organizado
